# Visible Shields and Weapon Sets

A Baldur's Gate 3 mod. Your shield stays on your back when weapons are put away, both weapon sets
are shown at once, and every weapon slot gets a visibility toggle — per character, like the game's
own helmet toggle.

Items, stats and rules are not touched: a shield stays a shield. The mod only tells the engine what
to draw.

## What it does

- **Shield on the back** while weapons are sheathed — for the party, companions and NPCs.
- **Both weapon sets visible**: the bow stays on your back while you hold the sword, and the other
  way round.
- **A toggle next to each weapon slot** (melee main hand, melee off-hand, ranged main hand, ranged
  off-hand) with four settings:

  | Setting | The stowed weapon is shown… |
  |---|---|
  | Always show | always |
  | Show with current set | only while its weapon set is the one in use (as in the unmodded game) |
  | Hide in dialogues | everywhere except dialogues and cutscenes |
  | Always hide | never |

  A weapon in your hands is always shown. Settings are per character and saved with the game.
- Works in multiplayer and split screen: everyone sees the same thing, and only the player a
  character belongs to can change its settings.
- Works in the world, in dialogues and cutscenes, and in photo mode.
- **Keyboard and mouse:** hover a weapon slot in the character sheet or the party panel and click the
  eye button above it.
- **Controller:** character sheet → *Equipment Options* → *Main hand weapon* / *Off-hand weapon*
  (they act on the weapon set in use).
- Texts in all 15 languages of the game. English and Russian were written by hand; the rest are
  unreviewed translations — corrections are welcome.

## Requirements

- Baldur's Gate 3, Patch 8.
- [BG3 Script Extender](https://github.com/Norbyte/bg3se) v33 or newer.

Because it needs Script Extender, the mod is PC only and cannot be offered through the in-game mod
manager.

## Compatibility

- Mods that carry their own copies of the character sheet templates (Better Inventory UI does) must
  be loaded **before** this mod; otherwise the buttons disappear. The mod prints a warning to the
  Script Extender console when it detects this.
- Do not use together with other mods that put shields on the back.
- Modded shields and weapons work as they are.

## Known limitations

- Script Extender still calls a few of the fields this mod relies on by placeholder names and will
  rename them in a future version. The mod will need an update when that happens.

## Building from source

The mod is in `mod/`. `build.ps1` packs it and copies the package into the game's Mods folder (close
the game first). The UI libraries and the localization files are generated by the scripts in
`scripts/`; the UI ones are derived from the game's own files, which you extract yourself with
[LSLib](https://github.com/Norbyte/lslib). See [docs/how-it-works.md](docs/how-it-works.md) for how
the mod works and how to test it.
